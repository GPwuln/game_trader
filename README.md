# Game Trader - 游戏道具交易记录管理系统

一个功能强大的游戏道具交易记录管理系统，提供直观的界面来高效管理游戏道具交易数据。

## ✨ 主要特性

- 🎮 **道具管理** - 轻松添加、编辑和管理游戏道具信息
- 📊 **交易记录** - 完整的交易历史追踪和数据分析
- 🌓 **主题切换** - 支持明亮/暗黑主题，自动适配系统偏好
- 📱 **响应式设计** - 完美适配桌面端和移动端
- 💾 **本地存储** - 数据安全存储在本地浏览器
- 📈 **数据可视化** - 直观的图表展示交易趋势
- 🔍 **智能搜索** - 快速查找和筛选道具
- 📤 **导入导出** - 支持 JSON 格式的数据导入导出

## 🚀 快速开始

### 使用方法

1. 在浏览器中打开 `game_trader_enhanced.html` 文件
2. 开始添加您的游戏道具和交易记录
3. 所有数据将自动保存在浏览器本地存储中

### 系统要求

- 现代浏览器（Chrome、Firefox、Safari、Edge 等）
- 支持 HTML5 和 LocalStorage
- 建议使用最新版本的浏览器以获得最佳体验

## 📖 功能说明

### 道具管理
- 添加新道具，包含名称、分类、价格等信息
- 编辑和删除现有道具
- 按分类组织和查看道具

### 交易记录
- 记录每笔交易的详细信息
- 查看完整的交易历史
- 统计分析交易数据

### 数据管理
- 导出所有数据为 JSON 格式
- 从 JSON 文件导入数据
- 数据自动备份到浏览器本地存储

## 🛠️ 技术栈

- 纯 HTML5 + CSS3 + JavaScript
- 无需后端服务器
- 使用 LocalStorage 进行数据持久化
- 响应式设计，适配各种屏幕尺寸
